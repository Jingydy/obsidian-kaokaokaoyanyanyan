# 考考考研研研

一个轻量的 Obsidian 考研激励插件。

## 手动安装

1. 在 GitHub 的 Releases 页面下载 `kaoyan-motivation-v1.0.1.zip`。
2. 解压后得到 `kaoyan-motivation` 文件夹。
3. 将整个文件夹放入你的 Obsidian 仓库：

   ```text
   <你的仓库>/.obsidian/plugins/kaoyan-motivation/
   ```

4. 重启 Obsidian。
5. 打开“设置 → 第三方插件”，启用“考考考研研研”。

> [!tip]
> macOS 中如果看不到 `.obsidian`，可以在 Finder 中按 `Command + Shift + .` 显示隐藏文件。

## 功能

- 每天首次打开仓库时显示一条激励语
- 左侧星光按钮和命令面板随时“激励一下”
- 状态栏显示当前激励语
- 可设置考试日期并显示倒计时
- 使用插件目录内独立的 `研途星火语录.md` 管理全部语录
- 可在插件设置页或命令面板中添加自定义语录
- 外部修改语录文件后自动刷新，无需修改插件代码
- 一键复制，或以 Obsidian Callout 写入当前笔记

## 使用

1. 在“设置 → 第三方插件”中启用“考考考研研研”。
2. 在“设置 → 考考考研研研”中填写考试日期、目标名称或添加自定义语录。
3. 点击左侧星光按钮，或在命令面板搜索“考考考研研研”。

## 管理语录

语录存放在插件目录的 `研途星火语录.md`。每个顶层无序列表项代表一条语录：

```markdown
- 今天也要稳稳向前。
- 先完成今天最重要的一件事。
```

标题、说明、Callout 和缩进列表不会被识别为语录。

可以通过以下两种方式在 Obsidian 内添加：

1. 打开“设置 → 考考考研研研 → 添加自定义语录”。
2. 在命令面板运行“考考考研研研：添加自定义语录”。

## 更新

更新插件时，只替换以下文件：

- `main.js`
- `manifest.json`
- `styles.css`

请保留以下个人数据文件：

- `研途星火语录.md`
- `data.json`

直接覆盖语录文件会丢失用户自行添加的语录。

## 卸载

1. 在 Obsidian 的第三方插件设置中关闭“考考考研研研”。
2. 删除 `.obsidian/plugins/kaoyan-motivation` 文件夹。

## 隐私

插件完全在本地运行，不请求网络，也不会上传任何笔记内容。
